# Documentación - Reto ForIf

## Descripción

La serie de retos ForIf (Reto1.java - Reto21.java) es una progresión de ejercicios para aprender y practicar:
- Estructuras de control: bucles FOR, WHILE, DO-WHILE
- Operadores condicionales: IF, ELSE, SWITCH
- Variables contador y acumuladores
- Salida formateada en consola

## Estructura típica

Cada reto sigue este patrón:

```java
public class RetoN {
    public static void main(String[] args) {
        // Inicialización de variables
        // Bucles y condicionales
        // Salida de resultados
    }
}
```

## Progresión de dificultad

- **Reto 1-5**: Bucles y condicionales básicos
- **Reto 6-10**: Patrones de asteriscos e impresión formateada
- **Reto 11-15**: Lógica de números y secuencias
- **Reto 16-21**: Algoritmos moderadamente complejos

## Ejecución

```bash
javac Reto1.java
java Reto1
```

O compilar todos:

```bash
javac *.java
java Reto1  # Ejecuta el reto 1
java Reto2  # Ejecuta el reto 2
```

## Buenas prácticas observadas

- Uso consistente de camelCase para nombres de variables
- Indentación uniforme en bloques de control
- Nombres de clases en PascalCase (RetoN)
- Métodos auxiliares separados para mejorar legibilidad (si aplica)
